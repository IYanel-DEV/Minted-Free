[size=14][b][color=#E91E63]🎁 What's New in 0.67.0[/color][/b][/size]

[spoiler=💸 /donate — No-Fee Gifts with a Fanfare]
[list]
[*][b]New [b]/donate <player> <amount>[/b] command[/b] (alias [b]/tip[/b])
[*][b]No fee[/b] — every coin lands with the receiver
[*][b]Instagram-worthy arrival:[/b] the receiver gets the money, a chat line, and text floating [b]above the health bar[/b] (action bar)
[*][b]Fanfare melody[/b] plays around the receiver when the money lands
[*][b]Spam-proof music:[/b] the melody won't replay for the same receiver within [b][i]donate.music-cooldown-seconds[/i][/b] (default 5s)
[*][b]Tab completion[/b] lists online players
[/list]
[/spoiler]

[spoiler=🔐 Permissions]
[list]
[*][b][i]minted.donate[/i][/b] (default [b]true[/b]) — use [b]/donate[/b]
[*][b][i]minted.donate.others[/i][/b] (default [b]true[/b]) — tab-complete other players
[/list]
[/spoiler]

[size=14][b][color=#9C27B0]💰 Donation Configuration[/color][/b][/size]

[code]donate:
  # How long before the fanfare can play again for the same receiver (seconds)
  music-cooldown-seconds: 5

sounds:
  enabled: true
  volume: 1.0
  donate-sent: "NOTE_PLING"   # sound the donor hears[/code]

[size=14][b][color=#9C27B0]💻 In-Game[/color][/b][/size]

[code]/donate Steve 500       # give $500 to the online player Steve
/tip Steve 500              # same thing[/code]

[size=14][b][color=#00BCD4]📥 Installation & Upgrade[/color][/b][/size]

[b]Fresh Install:[/b]
1. Drop [b]Minted-0.67.0.jar[/b] in [i]plugins/[/i]
2. Start server — SQLite works with zero config
3. Try [b]/minted gui[/b] — personal hub with balance, bank, wallet, stats, requests

[b]Upgrade from Any Version:[/b]
1. Replace jar, restart
2. Existing global shops → auto-exported to [i]global-shops.yml[/i] exactly once
3. Existing player shops → already in database, no action needed
