[size=14][b][color=#9C27B0]⚙️ How to Set Up Discord Notifications[/color][/b][/size]

[b]One-Time Setup (2 minutes):[/b]
1. In Discord: Server Settings → Integrations → Webhooks → New Webhook
2. Copy the webhook URL
3. In [i]config.yml[/i]: set [b][i]discord.enabled: true[/i][/b] and [b][i]discord.default-webhook-url[/i][/b]
4. (Optional) set individual URLs per event under [i]discord.webhooks.[/i]
5. Restart the server — done!

[b]Fresh Install:[/b]
1. Drop [b]Minted-0.66.0.jar[/b] in [i]plugins/[/i]
2. Start server — SQLite works with zero config

[b]Upgrade from Any Version:[/b]
1. Replace jar, restart

3. Existing player shops → already in database, no action needed
